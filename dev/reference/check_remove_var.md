# Check remove_var

Check remove_var

## Usage

``` r
check_remove_var(remove_var)
```

## Arguments

- remove_var:

  Whether to remove variables with near-zero variance (`'nzv'`;
  default), zero variance (`'zv'`), or none (`NULL`).

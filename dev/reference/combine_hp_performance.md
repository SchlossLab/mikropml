# Combine hyperparameter performance metrics for multiple train/test splits

Combine hyperparameter performance metrics for multiple train/test
splits generated by, for instance, [looping in
R](http://www.schlosslab.org/mikropml/articles/parallel.md) or using a
[snakemake
workflow](https://github.com/SchlossLab/mikropml-snakemake-workflow) on
a high-performance computer.

## Usage

``` r
combine_hp_performance(trained_model_lst)
```

## Arguments

- trained_model_lst:

  List of trained models.

## Value

Named list:

- `dat`: Dataframe of performance metric for each group of
  hyperparameters

- `params`: Hyperparameters tuned.

- `Metric`: Performance metric used.

``` r
if (FALSE) { # \dontrun{
```
